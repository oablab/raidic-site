Raidic

AppleRAID를 스마트하게.
터미널은 필요 없습니다.

diskutil이 아는 모든 것을 한눈에

문제는 절대 놓칠 수 없게

성능이 저하된 세트는 카드 전체가 주황색으로 변합니다. 디스크 하나로 돌아가는 미러에는 이중화 없음 표시 — macOS가 "Online"이라고 보고하더라도. 누락된 멤버는 이름으로 명시됩니다.

바이트 단위의 재구축 진행률

diskutil은 정수 퍼센트만 보여줍니다. Raidic은 재구축된 바이트를 직접 읽어 시작 직후부터 0.12%, 진행 중에는 748 GB / 2 TB로 표시 — 5초마다 자동 갱신됩니다.

실전 RAID 워크플로를 위한 설계

🖱 디스크를 드래그하세요

물리 디스크를 RAID 세트에 드롭하면 멤버로 추가됩니다. 확인 한 번 후 재구축 시작 — 조용히 실행되는 일은 없습니다.

🧱 의도적인 성능 저하 RAID1

디스크 하나로 미러를 만들고 데이터를 옮긴 뒤 두 번째 디스크를 추가하세요. 클래식한 마이그레이션 워크플로를 기본 지원합니다.

🛟 곳곳의 안전장치

부팅 디스크는 후보에 나타나지 않습니다. 파괴적 작업은 세트 이름 입력이 필수. 용량이 부족한 디스크는 암호 입력 전에 차단됩니다.

🧭 볼륨 지도

마운트된 모든 볼륨의 파일 시스템, 마운트 위치, 여유 공간을 한눈에 — RAID 세트 위 APFS 컨테이너 안의 볼륨까지.

🔍 디스크 상세 정보

디스크를 클릭하면 모델명, 버스, SMART 상태, 파티션이 표시됩니다. "Samsung PSSD T7" 같은 브랜드명이 목록에 바로 보입니다.

🏷 나만의 라벨

세트 이름, 타입, 용량은 컬러 칩입니다. 클릭하면 색이 바뀌고 글자색은 자동으로 흑백 전환되어 항상 읽기 쉽습니다.

자주 묻는 질문

데이터가 있는 디스크에서 사용해도 안전한가요?

Raidic은 Apple이 제공하는 diskutil 엔진을 사용합니다. 목록 조회와 모니터링은 읽기 전용이며 암호가 필요 없습니다. 파괴적 작업 — 세트 생성, 멤버 추가 — 은 지워질 디스크를 명시하고 세트 이름 입력과 macOS 관리자 인증을 요구합니다.

성능 저하 상태의 RAID1을 만들 수 있나요?

네. 미러를 선택하고 디스크 하나만 선택하면 이중화 없이 시작된다는 경고와 함께 생성됩니다. 나중에 두 번째 디스크를 드래그하면 미러가 완성되고 진행률이 표시되는 전체 재구축이 시작됩니다.

macOS는 Online이라는데 왜 "이중화 없음"인가요?

멤버가 하나뿐인 미러를 macOS는 Online으로 보고합니다. 유일한 멤버가 정상이기 때문입니다. 하지만 디스크 하나는 곧 무장애성 제로 — Raidic은 이 상태를 명시적으로 경고합니다.

RAID 위의 APFS를 지원하나요?

네. RAID 세트에 APFS 컨테이너가 있으면 Raidic이 컨테이너를 따라가 실제 마운트된 볼륨을 찾아 이름, 마운트 위치, 여유 공간을 표시합니다.

내 디스크가 후보에 나타나지 않는 이유는?

부팅 디스크와 이미 다른 RAID 세트에 속한 디스크는 후보로 제공하지 않습니다. 삭제된 세트의 RAID 잔여물이 있는 디스크에는 라벨이 붙습니다 — 그대로 사용 가능하며 새 세트 생성 시 정리됩니다.

Raidic이 데이터를 전송하나요?

아니요. 네트워크 기능도, 분석 추적도 없습니다. macOS 자체 디스크 관리와만 통신합니다.

Apple Silicon Mac은 AppleRAID로 부팅할 수 있나요?

불가능합니다 — 이는 macOS의 제한이며 Raidic의 제한이 아닙니다. AppleRAID는 데이터 및 외장 디스크용입니다. 미러링된 백업 쌍 등에 적합합니다.
